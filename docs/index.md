# Dara Notes Help

Dara Notes keeps Markdown notes in a Git repository and syncs them across Android, iOS and
the desktop. It works with [Foam](https://foambubble.github.io/foam/) workspaces: it reads
Foam's settings and templates and follows its conventions for links, tags and daily notes,
so you can switch between the app and VS Code freely.

- [Getting started](getting-started.md): connecting a repository, and how syncing works.
- [Writing notes](writing.md): the editor, the preview, tags, checklists, daily notes,
  renaming and exporting.
- [Finding and organizing notes](organizing.md): the note list, the index note, the graph,
  connections, tags, orphans and placeholders.
- [Templates](templates.md): new-note and daily-note templates, writing templates in the
  app, picking one, and every template variable.
- [Foam and repository settings](foam-settings.md): the files in your repository that the
  app reads, such as `.vscode/settings.json`.
- [Troubleshooting](troubleshooting.md): sync problems, merge conflicts and settings that
  don't seem to apply.
- [Privacy policy](../PRIVACY.md): what the app stores and where it goes.

Dara Notes is an independent project, not made by or affiliated with the Foam developers.
The name and icon come from the Dara knot (Irish *doire*, oak), a Celtic knot whose
interlacing is read as an oak's roots: notes tied together by links.
